Roles:
- Administrator:
	- Name
	- Email
- Patient:
	- Name
	- Email
	- Medical history
	- Prescriptions
- Doctor:
	- Name
	- Email
	- Specialty
	- Location
- Prescription:
	- Patient name
	- Doctor name
	- Name
	- Dosage
	- Frequency
	- Duration
	- Pharmacy
	- Expiration date

Appointments:
- Date
- Time
- Patient name
- Doctor name
- Status (scheduled, completed, cancelled)

Patient:
- Book an appointment
- See available slots
- Choose a slot
- View a list of upcoming and past appointments
- Receive a notification when an appointment is booked
- Reschedule an appointment
- Cancel an appointment
- Be informed if I try to cancel an appointment within 48 hours before the appointment
- Receive reminders for upcoming appointments
- Search for doctor by name, specialty, or location
- Filter my appointments by upcoming, past or cancelled
- Receive a notification if an appointment is rescheduled or cancelled
- Provide feedback on the appointment
- Join virtual consultation
- Update personal information and medical history
- Access easily to cancellation and rescheduling policies
- Receive a prescription
- See list of prescriptions
- Receive a notification when the doctor issues a new prescription
- Request a prescription renewal
- Know when my prescription is about to expire
- Share my prescription with a pharmacy
- Receive a notification if the doctor updates or cancels my prescription

Doctor:
- View a list of upcoming appointments
- Filter appointments by date, patient name, or status
- See the patient's details and medical history
- Receive a notification when a patient books or cancels an appointment
- Mark an appointment as completed
- Reschedule an appointment
- Block unavailable slots
- Send messages to patients
- Request additional information from the patient
- Access to patient's medical history
- Generate a report of my daily or weekly appointments
- Export my appointments data to a CSV or PDF file
- Track the number of no-show patients or last-minute cancellations
- Define duration of appointments
- Issue a prescription
- View and manage prescriptions
- Send a prescription to a pharmacy
- Print or download a prescription
- Be alerted about potential drug interactions when prescribing medication
- Set prescription renewal conditions
- Attach special instructions to a prescription

Administrator:
- Manage users:
	- Create new users
	- Edit user information (name, email, role)
	- Deactivate/reactivate users
	- Prevent duplicate email addresses
	- Receive a notification after successful changes
- View all appointments (upcoming, past, cancelled) including date, time, patient name, doctor name, status (scheduled, completed, cancelled)
- Filter appointments by date, patient name, or doctor name
- Cancel an appointment on behalf of a patient
- Override cancellation restrictions
- Manage doctor schedules:
	- Generate reports
	- Filter reports by date, doctor name, or patient name
	- Export reports to a CSV or PDF file
- View and manage system logs
- Send system notifications
